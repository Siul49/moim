# **1\. 문제 인식 (Problem)**

## **1-1. 창업 배경 및 개발동기**

**창업 아이템 소개**

**MOIM(모임)** \- 대학생의 모임 일정 조율 과정을 자동화하는 웹 기반 서비스

* 참여자가 하나의 링크를 통해 자신의 캘린더 또는 에브리타임 시간표를 연동  
* AI가 모두의 공통 가능 시간을 자동으로 찾아 추천  
* 확정된 일정을 각자의 캘린더에 자동으로 바로 추가

**창업 동기**

* 조별과제, 동아리, 스터디 등 모임 일정을 잡을 때마다 에브리타임 시간표를 캡쳐해 공유하고, 카카오톡 대화방에서 가능한 시간을 하나씩 맞춰보는 과정이 반복됨  
* 개인 일정은 캘린더에 있고 수업 시간은 에브리타임에 따로 있어, 각각의 플랫폼을 오가는 과정이 불편함  
* 특히 여러 명이 참여하는 일정일수록 한두 명의 답변이 늦어지는 등 실제로 모두가 가능한 시간을 찾기까지 생각보다 많은 시간이 걸리며, 확정된 뒤에도 각자가 다시 캘린더에 입력해야 하는 과정이 불편함

 → 각자의 시간표와 캘린더 정보를 한 번만 반영하면 공통으로 가능한 시간이 자동으로 보이는 방식으로 줄일 수 있다고 판단

**비전 및 경영철학**

* **Vision:** 모든 대학생이 모임 시간 걱정 없이 활동에만 집중할 수 있는 캠퍼스  
* **Mission:** 반복적인 일정 조율의 마찰을 기술로 제거하여, 대학생 팀 활동의 실행력 증대

**창업 아이템의 기여도**  
MOIM은 기술적, 경제적, 사회적 세 측면에서 기여함

1. 기술적 기여: 에브리타임 시간표 이미지를 AI 비전 기술로 분석 → 수동으로만 처리하던 시간표 데이터를 자동화  
2. 경제적 기여: 대학생 한 명당 월 평균 2시간 이상 소모되는 일정 조율 시간을 절감 → 학업과 활동에 투입할 수 있는 시간 증가  
3. 사회적 기여: 일정 조율 실패로 인한 팀 활동 무산 감소 → 대학 내 협업 문화를 개선

## **1-2. 창업아이템의 목적 및 필요성**

**고객 설문 조사 결과 (28명 응답)**

문제의 빈번성과 심각성을 검증하기 위해 대학생 28명을 대상으로 설문 조사를 실시한 결과

| 조사 항목 | 결과 |
| ----- | ----- |
| 월간 일정 조율 빈도 | 3\~5회 50%, 6회 이상 18% |
| 1회 조율 평균 소요 시간 | 30분 이상 46%, 하루 넘게 끌린다 18% |
| 가장 짜증나는 순간 1위 | 다 정해놨는데 한 명이 안 된다고 할 때 (86%) |
| 가장 짜증나는 순간 2위 | 누가 응답 안 해서 한참 기다릴 때 (68%) |
| 모임 무산/연기 경험 | 가끔+자주 있다 79% (22명) |
| 현재 조율 방법 만족도 | 평균 3.0/5점 (보통 수준) |
| MOIM 사용 의향 | 평균 3.9/5점 (긍정적) |
| 베타 테스터 신청 | 32% (9명) 자발적 신청 |

**문제 우선순위 매트릭스**

설문 결과를 토대로 대학생 일정 조율의 핵심 문제를 세 가지로 정리

**1\) 정보 분산**

* 수업 시간은 에브리타임에, 개인 일정은 캘린더에, 조율 대화는 카카오톡에 흩어져 있어 한 번에 확인하기 어려움  
* 응답자의 93%가 카카오톡(채팅 또는 투표)으로 조율하고 있어, 별도 도구로의 전환 비용이 핵심 장벽임

**2\) 응답 지연 & 확정 후 번복**

* 가장 큰 불편으로는 68%가 응답 지연을, 86%가 확정 후 번복을 꼽음  
* 수동 방식에서는 모든 참여자가 응답할 때까지 기다려야 하므로 한 명의 지연이 전체 일정을 막는 문제점 발생함

**3\) 반복 입력으로 인한 피로도 증가**

* 확정된 일정을 다시 캘린더에 수동 입력해야 하는 문제(14%)  
* 기존 일정 조율 서비스에 매번 시간을 체크 하는 문제(14%)

**대체수단 분석**

기존의 일정 조율 방식과 MOIM의 차별점을 비교

| 구분 | 카카오톡(채팅/투표) | When2meet | MOIM |
| ----- | ----- | ----- | ----- |
| **입력 방식** | 텍스트 대화로 수동 비교 | 매번 시간 그리드 직접 클릭 | 캘린더/시간표 자동 연동 또는 그리드 클릭 |
| **시간표 반영** | 캡처 이미지 공유 후 눈으로 비교 | 수동 입력 필요 | 에브리타임 이미지 AI 자동 분석 |
| **결과 확인** | 대화를 다시 읽어 확인 | 겹치는 색상 눈으로 확인 | 공통 가능 시간 자동 계산 및 추천 |
| **확정 후 처리** | 각자 캘린더 재입력 | 각자 캘린더 재입력 | 캘린더 자동 추가 및 카톡 공유 |
| **카톡 공유** | 기본 지원 | 링크 복사 후 수동 공유 | 카카오 공유 API 기본 내장 |

## **1-3. 목표시장 분석**

**초기 목표시장**  
국내 대학생 중 조별과제, 동아리, 스터디, 공모전, 팀 프로젝트를 자주 수행하는 사용자

* 조율의 대부분은 카카오톡 단체방에서 이루어지며, 설문 응답자 28명 중 68%(19명)가 월 3회 이상 일정 조율  
*  팀 활동이 많은 전공, 창업팀, 동아리 운영진은 매주 여러 차례 시간을 맞추는 반복 수요가 있음  
* 목표 고객의 핵심 특성 \- 문제 인식이 분명하지만 새로운 서비스 도입에는 부담을 느낌  
* 설문에서 친구들이 같이 안 쓸 것 같다(43%)를 가장 큰 걱정으로 꼽음

→ MOIM은 웹 링크 기반 접근, 카카오톡 공유, 소셜 로그인으로 첫 사용의 부담을 최소화하는 방향으로 설계

매력적 기능 선호도를 보면, 공통 빈 시간 자동 추천(50%)과 에브리타임 시간표 자동 불러오기(43%)가 가장 높음

**정량적 시장 규모 (TAM-SAM-SOM)**

플랫폼 거래액(GMV) 기준의 객관적 데이터 및 지표를 기반으로 한 MOIM의 목표 시장 규모 산정은 다음과 같습니다.

| 시장 구분 | 대상 정의 및 근거 데이터 (GMV 기준) | 금액 규모 (연간) |
| :---: | :--- | :---: |
| **TAM (전체 시장)** | **국내 F&B 및 상업용 공간 예약 중개 전체 시장**<br>- 국내 전체 외식 및 공간 대여 총 시장 거래액 규모 추산 | 약 3조 원 |
| **SAM (유효 시장)** | **국내 대학생 단체 활동 유저 모임 총 지출액 (300만 명)**<br>- 전국 대학생 300만 명 × 연 16회 모임 × 회당 평균 지출액 15,000원 | 약 7,200억 원 |
| **SOM (수익 시장)** | **수도권 대학 초기 얼리어답터 지출액 (침투율 5%)**<br>- 수도권 대학생 58,500명 × 연 16회 모임 × 회당 평균 지출액 15,000원 | 약 140.4억 원 |

**※ 시장 규모(TAM-SAM-SOM) 산출 근거 및 데이터 출처**

MOIM의 정량적 시장 규모는 대학생 행동 데이터 및 국가 공인 통계 자료를 바탕으로 신뢰성 있게 도출되었습니다.

1. **TAM (전체 시장) 산출 근거 및 데이터**:
   - **데이터 출처**: 대한민국 통계청 소상공인 실태조사(외식업 총 매출) 및 F&B 상권 매출 통계자료, 국내 상업용 공간 예약 및 공유 경제 시장 분석 리포트.
   - **상세 논리**: 국내 전체 F&B 외식 시장 규모(약 120조 원) 중 단체 활동, 조별과제, 동아리 뒤풀이 등 단체 모임 목적의 결제액 비중을 보수적으로 약 2%로 산정하고, 국내 공간 대여(스터디룸, 파티룸, 연습실 등) 연간 시장 거래 규모(약 6,000억 원)를 합산하여 단체 모임 중개 대상 전체 시장 규모인 **약 3조 원**을 도출했습니다.

2. **SAM (유효 시장) 산출 근거 및 데이터**:
   - **데이터 출처**: 대한민국 교육부 대학알리미(Academy Info) 전국 대학 재학생 통계(2025년 기준), MOIM 자체 사용자 설문조사 결과.
   - **상세 논리**:
     - **대상 모수**: 전국 대학 재학생 총합 약 **300만 명** (교육부 통계).
     - **단체 모임 빈도**: MOIM 유저 설문조사 데이터상 전체 대학생의 68%가 월 3회 이상(학기 중 시험 기간 제외 연평균 **16회**) 일정 조율을 거치는 단체 활동(조별과제, 동아리, 학회, 공모전 등)을 정기적으로 수행합니다.
     - **모임 평균 지출액**: 1회 모임 시 단체 식당 식사비 및 카페, 스터디룸 이용료 등을 포함한 1인당 평균 단체 소비 지출액 **15,000원** 적용.
     - **연산 공식**: $3,000,000\text{명(전국 대학생)} \times 16\text{회/연} \times 15,000\text{원} = 7,200\text{억 원}$.

3. **SOM (수익 시장) 산출 근거 및 데이터**:
   - **데이터 출처**: 서울시 및 수도권 대학 재학생 통계자료(서울/경기 지역 주요 4년제 대학 재학생 수), MOIM 서비스 초기 침투율 목표치(5%).
   - **상세 논리**:
     - **초기 타겟 범위**: 서울/수도권 대학 재학생 약 117만 명 중, 숭실대학교를 중심으로 인근 주요 협력 대학의 동아리, 학회, 조별과제 코어 유저층 침투율 **5%** 가정 ($1,170,000\text{명} \times 5\% = 58,500\text{명}$).
     - **연산 공식**: $58,500\text{명(수도권 5% 유저)} \times 16\text{회/연} \times 15,000\text{원} = 140.4\text{억 원}$.



**2\. 실현가능성 (Solution)**

## **2-1. 사업화 전략**

**가치제안 정의**

**MOIM의 핵심 가치제안**

링크 하나로 모두의 빈 시간을 자동으로 조율

* 카카오톡 조율 방식 대비 시간 절감으로 기존 30분\~하루 이상 걸리던 조율 과정을 연동을 통해 5분 이내로 단축  
* 에브리타임 시간표와 캘린더를 통합 반영하여 수업과 개인 일정 관리의 분리 플랫폼 문제를 해결  
* 확정된 일정이 자동으로 캘린더에 추가되어 재입력 없이 기록이 완성 및 편리함 제공

**핵심기능 선정**

MVP는 모임 시간 자동 조율이라는 한 가지 흐름에 집중 

| 순서 | 기능 | 설명 |
| :---: | ----- | ----- |
| 1 | 모임 생성 | 호스트가 모임 제목, 후보 날짜 범위를 설정 → 공유 링크 생성 |
| 2 | 카카오톡 공유 | 카카오 Share API를 통해 단체방에 링크 공유 가능 |
| 3 | 일정 입력/연동 | Google/Apple 캘린더 연동, 에브리타임 시간표 이미지 업로드(Gemini Vision API 분석), 또는 시간 그리드 직접 클릭 중 선택 가능 |
| 4 | 공통 가능 시간 확인 | 모든 참여자의 가능/불가능 시간을 통합 계산하여 공통 가능 시간대를 시각적으로 표시 |
| 5 | 일정 확정 및 자동 추가 | 호스트 모임 일정 확정 →연동 참여자: 캘린더에 자동 추가 →비연동 참여자: .ics 파일 또는 캘린더 추가 버튼을 제공 |

**시제품(MVP) 구현 현황 및 주요 화면 구성**

현재 MOIM 플랫폼은 프론트엔드 및 백엔드 핵심 연동이 완료되어, 모임 생성부터 최종 시간표 파싱 및 일정 조율 완료까지의 전체 흐름이 정상 구동되는 시제품(MVP) 개발을 완료한 상태입니다. 각 단계별 주요 화면의 기능과 구성은 다음과 같습니다.

* **[화면 1] 모임 일정 조율 생성 및 호스트 공유 링크 발급**

**기술 타당성 검토**

**기술적 보안성: 프라이버시 보호를 위한 이중 아키텍처 (Decoupled Dual Architecture)**

사용자의 개인 캘린더나 에브리타임 시간표는 민감한 개인 정보(수업 시간, 개인 스케줄 등)를 담고 있어, 외부 대형 언어 모델(LLM)에 그대로 전송하여 연산하는 방식은 데이터 유출 및 프라이버시 침해 우려가 있습니다. MOIM은 이 문제를 해결하기 위해 **이중 아키텍처(Dual Architecture) 설계**를 도입하여 개인 정보를 원천 보호합니다.

1) **정량적 일정 조율 연산 (내부 결정론적 알고리즘)**
   - 참여자의 시간표와 캘린더 일정은 외부 AI에 절대 전송되지 않습니다.
   - 데이터베이스(Supabase) 및 Next.js 코어 서버 내에서 수학적/결정론적(Deterministic) 가용시간 매칭 알고리즘을 통해 서버 내부에서 즉각 100% 안전하게 연산합니다.
2) **비정형 맥락 해설 생성 (외부 AI 분리 연동)**
   - 개인 식별 정보와 상세 스케줄이 모두 제거된 **최종 공통 일정의 시간대(예: "금요일 오후 3시~6시")**와 **모임의 성격(예: "스터디 모임")**만을 추출합니다.
   - 정제된 익명 텍스트 정보만을 Gemini API로 송신하여 사용자에게 친숙한 문장 형태의 일정 추천 해설(예: "금요일 오후 시간대는 팀원 전원의 수업 일정이 마쳐진 후로 이동 시간이 여유롭고, 협업 효율이 극대화될 것입니다.")을 동적으로 생성합니다.

이와 같은 이중 구조 설계를 통해 **개인 정보 유출의 법적/기술적 리스크를 원천적으로 차단하면서도 AI를 활용한 고부가가치 요약 해설 기능을 동시에 안전하게 구현**하였습니다.

# **3\. 성장 전략 (Scale-up)**

## **3-1. 시장진입 및 성과창출 전략**

**초기 GTM(Go-to-Market) 전략**

**시장 진입**

* 조별과제와 동아리 대상으로 일정 조율이 잦은 팀 대상으로 베타테스트 및 프로토타입 사용 제안   
* 실제로 시간이 단축되었는지, 어떤 화면에서 막히는 지 확인 및 검증  
* 초기 메시지는 “카카오톡으로 링크 하나만 보내면 모두의 가능한 시간이 보인다” 로 설정

**채널 및 퍼널 설계**

확산은 제품 자체의 공유 구조를 활용함.

* 제품 자체 바이럴 구조 **:** 한 명이 모임 링크를 만들면 여러 참여자가 동시에 서비스를 경험   
* 일정 확정 후 결과 공유 화면에 다음 일정 생성 링크를 포함하면, 참여자가 다음에는 직접 호스트가 되는 흐름도 기대 가능   
* 공유구조를 이용해 별도 마케팅 비용 없이 자연스러운 확산을 추구

**시장 확장 로드맵**

| 단계 | 목표 시장 | 주요 활동 |
| :---: | ----- | ----- |
| 1단계 (1\~2학기) | 소속 대학 내 조별과제/동아리 팀 | 프로토타입 테스트, 핵심 흐름 검증, 피드백 기반 개선 |
| 2단계 (3\~4학기) | 수도권 주요 대학 확산 | 에브리타임 커뮤니티 홍보, 학생회/동아리 연합 파트너십 |
| 3단계 (2\~3년) | 전국 대학 및 대학 조직 단위 | 창업지원단, 연구실, 학과 단위 도입 및 제휴처 확대 |


**가격 및 수익모델: 4단계 선순환 비즈니스 로드맵**

플랫폼의 지속 가능한 성장과 초기 대학생 유저의 이용 장벽 제거를 위해 B2C 유저 대상 전면 무료화로 시작해 B2B 가맹 매장으로 수익 구조를 전환해 나가는 **4단계 선순환 비즈니스 모델(BM Flow)**을 채택하고 있습니다.

1) **1단계: B2C 무료 선점 및 로컬 광고 (Phase 1)**
   - 대학생들의 서비스 가입 및 사용 이탈을 없애기 위해 일정 조율 기능은 100% 무료로 배포합니다.
   - 방장(호스트)이 일정을 조율하기 위해 공통 추천 시간을 연산하는 약 5초의 로딩 시간 동안 대학가 인근 매장의 제휴 광고 배너(예: "숭실대 정문 더블랙 스터디카페 10% 단체 할인 쿠폰")를 자연스럽게 노출시켜 초기 서버비 및 API 비용 등의 고정 운영비를 확보합니다.

2) **2단계: 유저 선호 공간 행동 데이터 트래킹 (Phase 2)**
   - 일정이 확정된 유저들에게 주변 모임 장소 추천 디렉토리를 제공하여, 유저들이 어떤 유형의 매장(단체 식당, 룸카페, 스터디룸 등)을 조회하고 공유하는지 등의 선호도 및 행동 데이터를 축적하여 분석합니다.

3) **3단계: 리뷰-할인 매칭 제휴 GTM (Phase 3)**
   - 분석된 선호 데이터를 바탕으로 상권 내 표적 매장들을 영업합니다. 모임의 방장 1인이 매장 이용 후 영수증 리뷰 작성(인증)을 완료하면 단체 할인 혜택을 매칭해 주는 구조를 적용합니다. 이를 통해 가맹 매장에는 플레이스 리뷰 평판 상승 및 오프피크(Off-peak) 매출 증대를 보장하고, 유저에게는 실질적 혜택을 제공합니다.

4) **4단계: B2B SaaS 구독 솔루션 및 중개 수수료 전환 (Phase 4)**
   - 플랫폼을 통한 실제 매출 상승 성과가 검증되어 매장의 플랫폼 의존성(Lock-in)이 확보된 시점에 월 29,000원의 소상공인 솔루션 구독료와 건당 3.3%의 예약 중개 수수료 과금 체계로 전환하여 수익 구조를 극대화합니다.

**사업 목적: 재무적 목표**

* **1단계(MVP 검증기):** 매출보다 사용자 반복 사용률 확인에 집중하며, 본교(숭실대) 단체 손님 무료 제휴를 통해 초기 활성 유저 유입에 집중함.
* **2단계(확산기):** 대학 단위 사용자 확보 및 수도권 주요 대학 침투(SOM 침투율 5% 달성)를 목표로 함.
* **3단계(수익화 안착기):** 플랫폼 거래액(GMV)에 기반한 **5단계 순매출(Net Revenue) 파이프라인**을 작동시켜 수익성 극대화 및 자립 기반 확보.

**※ MOIM 연간 순매출(Net Revenue) 산출 공식 파이프라인**
1. **SOM GMV (Step 1)**: 수도권 대학 5% 침투 시 거래액 **140.4억 원** 확보.
2. **중개 거래액 전환 (Step 2)**: 전체 모임 중 플랫폼을 통한 제휴 매장 예약 전환율을 25%로 가정하여 **35.1억 원**의 예약 거래액 발생.
3. **중개 수수료 매출 (Step 3)**: 제휴 매장 대상 중개 수수료 3.3% 적용 시, 수수료 순매출 **1.17억 원** 발생.
4. **SaaS 및 로컬 광고 매출 (Step 4)**: 제휴 상권 광고 구좌 판매 및 가맹점 솔루션(월 29,000원 SaaS 구독료)을 통해 부가 매출 **3,500만 원** 확보.
5. **최종 연간 목표 순매출 (Step 5)**: 수수료 매출(1.17억) + 부가 매출(3,500만) = **연간 총 1.52억 원**의 초기 순매출 달성.

**정량적 인프라 규모 산정 및 단계별 확장 계획**

초기 타겟팅하는 수익시장(SOM) 규모인 **수도권 대학생 유저 58,500명** 유입 및 서비스 활성 단계를 기준으로 한 인프라 부하(트래픽, 스토리지, API 비용) 산출 근거 및 단계별 스케일업 계획은 다음과 같습니다.

1) **트래픽 및 동시접속자(Active Connection) 부하 산출**
   - **산출 근거**: 설문조사 통계상 대학생 1인당 연평균 모임 조율 횟수 **16회** 및 평균 모임원 수 **5명** 적용.
   - **연간 총 조율 요청 수**: $58,500\text{명} \times 16\text{회} / 5\text{명} = 187,200\text{회 / 연}$.
   - **월평균 조율 수**: $187,200\text{회} / 12\text{개월} = 15,600\text{회 / 월}$.
   - **학기 중 피크 타임 가중치**: 대학 활동의 학기 중 집중(3~6월, 9~12월) 현상을 고려해 가중치 1.5배 적용 시, 피크 월 **23,400회 조율** 발생.
   - **일일 평균 조율 발생량**: $23,400\text{회} / 30\text{일} = 780\text{회 / 일}$.
   - **서버 트래픽 부하**: 일평균 780회 조율방 개설 시 모임원 5명 참여 기준 일일 총 요청 수(Request)는 약 $780\text{회} \times 5\text{명} \times 3\text{회(생성/입력/확정)} = 11,700\text{ requests / 일}$. 초당 최대 요청 수(TPS) 기준 5 미만으로, **Vercel의 Serverless Function 기본 대역폭(Pro 플랜 1TB/월) 범위 내에서 100% 소화 가능**합니다.

2) **데이터베이스 레코드 및 스토리지(Storage) 부하 산출**
   - **산출 근거**: 설문조사 응답자 중 **43%**가 에브리타임 시간표 자동 연동(OCR 이미지 업로드) 기능을 핵심 선호 기능으로 지목.
   - **연간 이미지 업로드 횟수**: $58,500\text{명} \times 43\% = 25,155\text{장 / 연}$.
   - **스토리지 요구량**: 에브리타임 시간표 평균 캡처 이미지 용량 300KB 기준, $25,155\text{장} \times 300\text{KB} = 7.54\text{GB}$.
   - **DB 레코드 스토리지**: 조율방 메타데이터 및 유저 정보 레코드당 50KB 기준, $187,200\text{개} \times 50\text{KB} = 9.36\text{GB}$.
   - **총 필요 데이터 볼륨**: 약 **17GB / 연**으로, **Supabase Pro 플랜의 기본 디스크(8GB DB 및 100GB 스토리지) 제공 범위 내에서 안정적인 운영이 가능**합니다.

3) **Gemini API 연동 비용 산출**
   - **산출 근거**: 에브리타임 이미지 파싱(25,155회) 및 최종 일정 자연어 요약문 생성(187,200회).
   - **사용 요금**: Gemini 1.5 Flash API 기준(Input $0.075 / 1M tokens, Output $0.3 / 1M tokens).
   - **회당 평균 소모 토큰**: 약 1,500 tokens.
   - **연간 총 API 소모 토큰**: $(25,155\text{회} + 187,200\text{회}) \times 1,500\text{ tokens} = 318,532,500\text{ tokens / 연}$.
   - **연간 총 API 소요 비용**: 약 $3.18\text{억 tokens} \times \text{평균 } \$0.15 / 1M\text{ tokens} \approx \$47.7\text{ (한화 약 6만 5천 원 / 연)}$. 인프라 유지비용 대비 극강의 수익 효율을 보장합니다.

4) **단계별 클라우드 인프라 확장 로드맵**
   - **1단계: MVP 시장 검증 (숭실대 선점기, MAU 1,000명 미만)**
     - 구성: Vercel Free 플랜 + Supabase Free 티어 (DB 500MB, 스토리지 1GB) + Gemini API 무료 사용량.
     - **인프라 고정 비용: 월 0원**.
   - **2단계: 상권 제휴 및 수도권 확산 (MAU 10,000명 미만)**
     - 구성: Vercel Pro 플랜(월 $20) + Supabase Pro 티어(월 $25, 8GB DB/100GB 스토리지 제공).
     - **인프라 고정 비용: 월 $45 (한화 약 6만 원)**.
   - **3단계: 수익화 안착 및 확장 (MAU 50,000명 이상)**
     - 구성: Supabase Pro 티어 + 종량제 디스크 증설 요금 적용 + Gemini API Pay-as-you-go 전환.
     - **인프라 고정 비용: 월 약 15만 원 수준**. 목표 순매출인 연 1.52억 원 대비 **인프라 비용 부담률이 1.2% 미만**에 불과하여 98% 이상의 높은 영업이익률 유지가 가능합니다.

# **4\. 팀 구성 (Team)**

PSST 모델의 핵심 질문: 왜 우리가 이 문제를 가장 잘 푸는가?

## **4-1. 창업자의 역량**

팀장 **김경수**는 글로벌미디어학부 소속으로 프로젝트 방향 설정, 스프린트 관리, 코드 리뷰, 백엔드 설계를 담당

*  합주실 예약 서비스 운영 경험을 통해 예약 흐름과 일정 데이터 관리의 실제 문제를 경험  
* 여러 웹 프로젝트를 빠르게 시도하며 제품 검증과 구현 사이의 균형을 익힘  
* 창업자로서의 강점은 문제를 직접 겪은 사용자이자 구현을 주도할 개발자라는 점점

팀원 **김유현**은 글로벌미디어학부 소속으로 전반적이 UX/UI 디자인과 프론트엔드 개발 담당

* 풀스택으로 프로젝트를 진행한 경험을 바탕으로 프론트엔드와 백엔드 간 원만한 의사소통 가능  
* 여러 웹 & 앱 프로젝트 경험으로 간편한 사용자 흐름 제안

팀원 **이동은**은 예술창작학부 소속으로 서비스 소개 영상, 카드뉴스 제작, 온보딩 UX 검토를 담당

*  Premiere, Photoshop 작업 경험을 활용한 홍보 영상 및 카드뉴스 제작으로 브랜드 이미지 구축  
* 사용자 관점에서의 UX 검토를 통해 서비스 진입 장벽을 낮추고, 브랜드 정체성이 일관되게 유지되는 디자인 환경 구축

팀원 **이동윤**은 경영학부 소속으로 기획, 마케팅, 재무를 담당

* 재무, 회계, 마케팅 등 경영 전반 전공 수강  
* 투자 학회를 통해 k뷰티 등 다양한 기업 및 산업 분석

팀원 **정규호**는 글로벌미디어학부 소속으로 백엔드 설계 및 개발을 담당

* 개발 스터디와 여러 프로젝트들을 통한 서비스 구현 경험과 운영 경험을 통해 문제해결 및 대응 능력을 기름  
* 원활한 서비스 운영과 내부 설계로 개발 및 유지보수 담당

## **4-3. 중장기 사회적 가치 도입계획**

MOIM은 오픈소스 실전 창업 수업의 취지에 맞게 핵심 일정 조율 로직과 기본 화면 일부를 오픈소스로 공개하는 방향을 검토함으로써 다음과 같은 사회적 가치를 추구

* **교육적 기여:** 대학생 개발자들이 실제 서비스의 코드를 보고 배울 수 있는 오픈소스 학습 자원을 제공  
* **커뮤니티 기여:** 개발자 커뮤니티가 코드를 검토하고 개선에 참여할 수 있는 구조를 만들어 오픈소스 생태계에 기여  
* **접근성 보장:** 기본 일정 조율 기능은 무료로 유지하여, 경제적 여건과 관계없이 모든 대학생이 효율적인 팀 활동을 할 수 있도록 함  
* **ESG 연계:** 장기적으로 장애 학생을 위한 접근성 기능(스크린 리더 지원, 고대비 모드)을 추가하여 포용적 서비스로 발전
